Corrida real contra el stack Docker, api-gateway en localhost:3000
$ bash testing/performance/run-autocannon.sh POST /auth/login p50 11ms p99 275ms 288 2xx / 24.637 no-2xx GET /products p50 10ms p99 32ms 0 2xx / 34.960 no-2xx GET /dashboard/summary p50 9ms p99 32ms 27 2xx / 35.012 no-2xx Hallazgo honesto: la latencia individual es excelente (milisegundos), pero bajo 20 conexiones concurrentes casi todas las respuestas NO son 2xx. Causa confirmada en el código: el api-gateway aplica @nestjs/throttler con un límite de 300 peticiones/minuto — es una protección deliberada, no un bug. Conclusión: el sistema no está dimensionado para más de ~5 peticiones/segundo sostenidas por el gateway tal como está configurado hoy.
