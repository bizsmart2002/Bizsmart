BizSmart — Regresión (testing/run-all.sh)

Un solo comando encadena los 4 niveles automatizados: unitarias → integración mock → integración real → sistema/API
$ bash testing/run-all.sh 1) PRUEBAS UNITARIAS (Jest, mocks, 8 servicios) .......... 61/61 OK 2) INTEGRACIÓN (capa HTTP con mocks) — auth-service e2e ... 5/5 OK 3) INTEGRACIÓN REAL (sin mocks, stack Docker) ............ 4/4 OK 4) SISTEMA / API (Postman + Newman) ...................... 273/276 OK ❌ 3 aserciones en rojo (hallazgos ya conocidos, NO regresiones nuevas): · POST /products nombre 10.000 chars -> 500 (debería ser 400) · GET /inventory/:id inexistente -> 500 (debería ser 404) El script marca la corrida en rojo mientras esos 2 defectos sigan abiertos — es justamente su función: avisar que algo conocido (y SOLO eso) sigue roto, sin maquillar el resultado. El flujo de venta E2E (antes el hallazgo crítico) pasa COMPLETO.
